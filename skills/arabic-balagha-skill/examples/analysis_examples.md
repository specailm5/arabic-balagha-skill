# نماذج تحليل بلاغي — مهارة البلاغة

> ثمانية نماذج: النص، النوع، الأركان/القرائن، الوظيفة، الحكم.

---

## ١. «العلم في الصدر كالشمس في الفلك»

| البند | البيان |
| :--- | :--- |
| **النوع** | تشبيه مرسل مجمل |
| **المشبه** | العلم في الصدر |
| **المشبه به** | الشمس في الفلك |
| **وجه الشبه** | الإشراق والظهور |
| **الأداة** | الكاف |
| **الوظيفة** | بيان حال المشبه، ونقل المعنى المجرد إلى صورة حسية |
| **الحكم** | صورة سليمة واضحة، لكنها قريبة المأخذ |

**الشرح:** جعل العلم مرئياً كالشمس، فأخرج المعنى العقلي إلى صورة محسوسة. وحذف وجه الشبه جعل السامع يستخرجه بنفسه، فزاد الأثر.

---

## ٢. «زيد أسد»

| البند | البيان |
| :--- | :--- |
| **النوع** | تشبيه بليغ |
| **المشبه** | زيد |
| **المشبه به** | الأسد |
| **وجه الشبه** | الشجاعة |
| **الأداة** | محذوفة |
| **الوظيفة** | المبالغة في المدح |
| **الحكم** | صورة قوية، لكنها مبتذلة بكثرة الاستعمال |

**الشرح:** حُذفت الأداة والوجه، وادّعي أن زيداً هو الأسد. وقوتها من ادعاء الاتحاد، وضعفها من ابتذالها.

---

## ٣. «رأيت أسداً في المدرسة»

| البند | البيان |
| :--- | :--- |
| **النوع** | استعارة تصريحية أصلية |
| **المستعار له** | الرجل الشجاع |
| **المستعار منه** | الأسد |
| **المستعار** | لفظ «أسد» |
| **القرينة** | «في المدرسة» |
| **الوظيفة** | المبالغة في وصف الرجل |
| **الحكم** | صورة واضحة، لكنها شائعة |

**الشرح:** ذُكر المشبه به فقط، وحُذف المشبه. والقرينة «في المدرسة» تمنع إرادة الأسد الحقيقي.

---

## ٤. «أنشبت المنية أظفارها بفلان»

| البند | البيان |
| :--- | :--- |
| **النوع** | استعارة مكنية |
| **المستعار له** | الموت |
| **المستعار منه** | السبع |
| **الرمز** | الأظفار |
| **القرينة** | «أنشبت» |
| **الوظيفة** | تجسيد الموت وتقويته |
| **الحكم** | صورة قوية، حسية، متماسكة |

**الشرح:** حُذف المشبه به (السبع)، ورُمز إليه بلازمه (الأظفار). فصار الموت مفترساً بلا تصريح.

---

## ٥. «طويل النجاد»

| البند | البيان |
| :--- | :--- |
| **النوع** | كناية قريبة عن صفة |
| **المكني عنه** | طول القامة |
| **اللازم** | طول النجاد (حمائل السيف) |
| **الوسائط** | قليلة |
| **الوظيفة** | المدح بلا تصريح |
| **الحكم** | كناية حسنة، واضحة |

**الشرح:** طول النجاد لازم لطول القامة، فذُكر اللازم وأُريد الملزوم. والوسائط قليلة، فلم تغمض.

---

## ٦. «كثير الرماد»

| البند | البيان |
| :--- | :--- |
| **النوع** | كناية بعيدة عن الكرم |
| **الوسائط** | كثرة الرماد ← كثرة الإحراق ← كثرة الطبخ ← كثرة الضيوف ← الكرم |
| **الوظيفة** | المدح بالكرم |
| **الحكم** | كناية جميلة إذا فُهمت، وغامضة إذا لم تُوضح |

**الشرح:** الوسائط كثيرة، فتحتاج إلى تأمل. ولذلك تُعدّ من الكنايات البعيدة.

---

## ٧. «يحيي ويميت»

| البند | البيان |
| :--- | :--- |
| **النوع** | طباق إيجاب |
| **الطرفان** | الإحياء / الإماتة |
| **الوظيفة** | تقوية المعنى بالقدرة المطلقة |
| **الحكم** | محسن معنوي، لا تكلف فيه |

**الشرح:** الجمع بين الضدين يبرز كمال القدرة، ويجعل المعنى أوضح.

---

## ٨. «فأما من أعطى واتقى...»

| البند | البيان |
| :--- | :--- |
| **النوع** | مقابلة |
| **الطرفان** | أعطى/بخل، اتقى/استغنى، صدق/كذب |
| **الوظيفة** | تقسيم الناس إلى فريقين |
| **الحكم** | مقابلة محكمة، تخدم المعنى |

**الشرح:** قابل بين الأفعال والنتائج على الترتيب، فصار البناء واضحاً.

---

## ٩. «والشمس كالمرآة في كف الأشل»

| البند | البيان |
| :--- | :--- |
| **النوع** | تشبيه مركب لهيئة الحركة |
| **المشبه** | الشمس |
| **المشبه به** | المرآة في كف الأشل |
| **وجه الشبه** | اضطراب الشعاع وتموجه |
| **الوظيفة** | تجسيد الحركة |
| **الحكم** | من أدق صور الحركة |

**الشرح:** لم يشبّه الشمس بالمرآة في الاستدارة فقط، بل في حركة المرآة المضطربة، فالتقط هيئة الحركة.

## ١٠. «ما كلفة البدر المنير قديمة...»

| البند | البيان |
| :--- | :--- |
| **النوع** | حسن التعليل |
| **العلة المعلنة** | أثر لطم على فراق الأحبة |
| **العلة الحقيقية** | طبيعية/فلكية |
| **الوظيفة** | إبداع علة طريفة |
| **الحكم** | من أجمل أمثلة حسن التعليل |

**الشرح:** أنكر المعري العلة الطبيعية، وأتى بعلة عاطفية لطيفة، فجعل الصورة أقرب إلى النفس.
